阶段一：Java 基础补强（第 1-4 周）

阶段 1 建议周期：4 周 | 每日 2 小时

目标：能写出可运行的 Java 程序，理解面向对象、集合、异常处理、常用数据结构，为 Spring Boot 打基础。

第 1 周 环境搭建 + 基础语法

  • 安装 JDK 17（推荐 LTS 版本），配置 JAVA_HOME 环境变量
  • 安装 IntelliJ IDEA（Community 版即可），创建第一个 Hello World 项目
  • 学习 Maven 安装与基础配置，了解 pom.xml 依赖管理
  • 学习 Git 基础命令（init、add、commit、push），注册 GitHub 账号
  • 掌握变量、数据类型（基本类型 + 包装类）、运算符
  • 掌握流程控制：if-else、switch、for、while、break/continue
  • 掌握方法（函数）定义与调用，理解参数传递（值传递）
  • 掌握数组定义、遍历、排序（冒泡排序手写一遍）
  • 【练习】写一个控制台程序：输入学生成绩，统计最高分/最低分/平均分

第 2 周 面向对象核心

  • 理解类与对象的概念，掌握构造方法、this 关键字
  • 掌握封装（private/getter/setter）、方法重载
  • 掌握继承（extends）、super 关键字、方法重写（@Override）
  • 掌握多态（向上转型/向下转型）、抽象类（abstract）
  • 掌握接口（interface）、实现（implements）、默认方法（default）
  • 掌握常用类：String、StringBuilder、Math、Date/LocalDate
  • 掌握包（package）与导入（import），理解访问修饰符（public/private/protected/default）
  • 【练习】设计一个"员工管理系统"控制台版：定义 Employee 类、Manager 子类，实现薪资计算多态

第 3 周 集合框架 + 异常处理

  • 掌握 List 接口：ArrayList、LinkedList 区别与使用场景
  • 掌握 Set 接口：HashSet、TreeSet 区别
  • 掌握 Map 接口：HashMap、LinkedHashMap、TreeMap，重点理解 HashMap 底层原理
  • 掌握泛型（Generic）基本用法，理解类型擦除
  • 掌握异常体系：Throwable → Error / Exception → RuntimeException
  • 掌握 try-catch-finally、throws、throw、自定义异常类
  • 掌握 Collections 工具类、Arrays 工具类常用方法
  • 【练习】用集合+异常处理重写员工管理系统，支持增删改查、异常提示

第 4 周 现代 Java + 阶段项目

  • 掌握 Lambda 表达式语法，理解函数式接口（Predicate、Consumer、Function、Supplier）
  • 掌握 Stream API：filter、map、sorted、collect、reduce
  • 掌握 Optional 避免空指针、LocalDate/LocalTime 日期处理
  • 掌握 IO 流基础（File、InputStream/OutputStream、Reader/Writer）
  • 了解线程基础：Thread、Runnable、线程池（Executors）
  • 【阶段项目】用 Java 控制台版实现"OA 审批流程模拟系统"
  • - 支持创建审批单、提交、审批通过/驳回、查看审批记录
  • - 使用集合存储数据，Stream API 做统计筛选
  • - 将项目代码上传到 GitHub，作为学习记录

阶段一里程碑

能独立写出面向对象 Java 程序，熟练使用集合与 Stream API，理解异常处理，代码已上传 GitHub

阶段二：Spring Boot 入门（第 5-9 周）

阶段 2 建议周期：5 周 | 每日 2.5 小时

目标：能用 Spring Boot 搭建 Web 应用，暴露 REST 接口，连接数据库，完成基础业务功能。

第 5 周 Spring 核心 + Spring Boot 入门

  • 理解 IOC（控制反转）思想，理解 DI（依赖注入）注解：@Component、@Autowired、@Service、@Repository
  • 理解 AOP（面向切面）基本概念，了解 @Aspect、@Before、@After 注解
  • 使用 Spring Initializr 创建 Spring Boot 项目，理解项目目录结构
  • 掌握 application.yml 配置文件编写，理解多环境配置（dev/test/prod）
  • 理解 Starter 自动配置原理，了解常见 Starter（web、mysql、mybatis）
  • 【练习】搭建一个空的 Spring Boot 项目，编写一个 HelloController 返回 JSON

第 6 周 Web 开发 + REST 接口

  • 掌握 @RestController、@RequestMapping、@GetMapping、@PostMapping 注解
  • 掌握请求参数接收：@PathVariable、@RequestParam、@RequestBody
  • 掌握统一响应封装：Result<T> 类（code、message、data）
  • 掌握 Controller → Service → Mapper 三层分层架构
  • 【练习】搭建"部门管理"接口：增删改查，返回统一 JSON 格式
  • 【练习】搭建"员工管理"接口：CRUD，部门关联（通过部门ID查找部门名称）

第 7 周 数据库 + MyBatis-Plus

  • 安装 MySQL 8.0，创建数据库和表（employee、department），写入测试数据
  • 掌握 JDBC 连接原理，了解 Druid 连接池配置
  • 掌握 MyBatis-Plus 基础：BaseMapper、@TableName、@TableId、@TableField
  • 掌握 MyBatis-Plus 常用 CRUD 方法：insert、deleteById、updateById、selectById、selectList
  • 掌握条件构造器：QueryWrapper、LambdaQueryWrapper（条件查询、分页、排序）
  • 【练习】将员工/部门接口的数据层改为 MyBatis-Plus，实现分页查询

第 8 周 接口文档 + 日志 + 单元测试

  • 集成 Swagger / Knife4j，配置 API 文档注解（@Api、@ApiOperation、@ApiParam）
  • 掌握 SLF4J + Logback 日志配置，了解日志级别（DEBUG/INFO/WARN/ERROR）
  • 掌握 JUnit 5 基础：@Test、@BeforeEach、@AfterEach、断言（assertEquals 等）
  • 【练习】为所有接口补充 Swagger 注解，编写核心 Service 的单元测试
  • 【阶段项目】完成"OA 审批流程后端系统"：员工 CRUD + 部门管理 + 审批任务 CRUD + Swagger 文档

第 9 周 阶段巩固 + 宜搭联动探索

  • 回顾阶段一 Java 基础薄弱点，查漏补缺
  • 了解宜搭开放 API 文档，理解宜搭的数据表单接口、流程接口
  • 尝试用 Spring Boot 调用宜搭的 HTTP 接口（获取表单数据/提交数据）
  • 【阶段项目完善】Spring Boot 后端能接收宜搭表单提交的数据，写入 MySQL
  • 将项目代码整理到 GitHub，写好 README 说明

阶段二里程碑

能独立搭建 Spring Boot 项目，完成 REST 接口开发 + 数据库 CRUD + Swagger 文档，并能与宜搭做基础数据联动

阶段三：REST 接口规范与工程化（第 10-13 周）

阶段 3 建议周期：4 周 | 每日 2 小时

目标：掌握规范的 RESTful 接口设计，能统一处理参数校验、异常、分页、日志等工程化问题。

第 10 周 RESTful 规范 + 参数校验

  • 学习 RESTful API 设计规范：资源命名（名词复数）、HTTP 方法语义（GET/POST/PUT/DELETE）
  • 掌握 HTTP 状态码规范：2xx 成功、3xx 重定向、4xx 客户端错误、5xx 服务端错误
  • 掌握参数校验：@Valid、@NotNull、@Size、@Email、自定义校验注解
  • 掌握请求 DTO 设计模式，禁止直接用 Entity 接收前端参数
  • 【练习】重构所有接口为规范 RESTful 风格，补充参数校验注解

第 11 周 全局异常处理 + 日志规范

  • 掌握 @ControllerAdvice + @ExceptionHandler 全局异常处理
  • 掌握自定义业务异常类（BusinessException），统一错误码规范
  • 掌握请求日志切面：用 AOP 记录所有接口的请求参数、响应结果、耗时
  • 掌握接口响应时间、分页参数的统一封装（PageResult）
  • 【练习】为项目添加全局异常处理和请求日志切面

第 12 周 文件上传 + 定时任务 + 缓存

  • 掌握文件上传：MultipartFile、文件存储路径配置、返回访问 URL
  • 掌握定时任务：@Scheduled 注解，Cron 表达式编写
  • 掌握 Spring Cache 基础：@Cacheable、@CacheEvict，集成 Redis 做缓存
  • 【练习】实现审批附件上传接口 + 定时发送审批超时提醒

第 13 周 接口版本管理 + 阶段整合

  • 掌握接口版本管理方案：URL 路径版本（/api/v1/）vs 请求头版本
  • 掌握接口幂等性设计基础概念
  • 掌握 Docker 基础：Dockerfile 编写、镜像构建、容器运行
  • 【练习】将 Spring Boot 项目打包成 Docker 镜像并运行
  • 【阶段整合】完善项目：版本管理 + Docker 部署 + 完整 API 文档

阶段三里程碑

能设计规范的 RESTful 接口，统一处理异常/日志/校验/分页，掌握 Docker 基础部署能力

阶段四：API 设计与系统集成（第 14-17 周）

阶段 4 建议周期：4 周 | 每日 2 小时

目标：掌握企业应用中最核心的接口对接能力：认证鉴权、第三方调用、Webhook 回调、钉钉接口集成。

第 14 周 JWT 认证 + 权限控制

  • 理解 JWT（JSON Web Token）结构：Header、Payload、Signature
  • 掌握 JWT 生成与解析：使用 jjwt 库实现登录生成 Token、拦截器校验 Token
  • 掌握基于角色的权限控制（RBAC）：用户-角色-菜单/权限关系模型
  • 掌握 Spring Security 基础配置（了解即可，重点理解认证流程）
  • 【练习】实现登录接口（生成 JWT）+ 接口拦截器（校验 Token）+ 角色权限注解

第 15 周 第三方接口调用

  • 掌握 RestTemplate 基础用法：getForObject、postForObject、exchange
  • 掌握 WebClient（响应式 HTTP 客户端）基础用法
  • 掌握 OkHttp 基础用法（了解备选）
  • 掌握第三方接口调用的最佳实践：超时配置、重试机制、熔断降级
  • 【练习】调用一个公开 API（如天气查询、IP 查询）并封装为工具类

第 16 周 Webhook 回调 + 钉钉接口

  • 理解 Webhook 概念：事件驱动、异步通知、回调 URL 设计
  • 掌握 Webhook 签名校验机制，防止伪造请求
  • 学习钉钉开放平台：创建企业内部应用、获取 AppKey/AppSecret
  • 掌握钉钉消息推送：工作通知消息、群机器人 Webhook 消息
  • 掌握钉钉审批流程 API：发起审批、查询审批状态、回调通知
  • 【练习】Spring Boot 集成钉钉，实现审批完成后自动发送钉钉消息通知

第 17 周 系统集成综合练习

  • 梳理宜搭开放 API 文档，理解数据表单 API、流程 API、用户组织 API
  • 实现 Spring Boot → 宜搭：通过 API 同步宜搭表单数据到自建数据库
  • 实现 Spring Boot ← 宜搭：宜搭流程回调通知 Spring Boot 处理业务逻辑
  • 实现钉钉 ← Spring Boot：审批结果通过钉钉推送给相关人员
  • 【阶段整合】完成"宜搭 + Spring Boot + 钉钉"三方联调，记录遇到的问题与解决方案

阶段四里程碑

能实现 JWT 认证鉴权、调用第三方接口、处理 Webhook 回调、集成钉钉开放平台，具备企业系统集成能力

学习原则与注意事项

30% 看教程 + 70% 动手写代码：不要陷入"只看不练"的陷阱。每学一个概念，立刻写代码验证。
不要一开始就深入底层原理：你的目标是"低代码+后端扩展"，不是成为纯 Java 架构师。理解概念和使用场景即可。
不要做与职业方向无关的项目：围绕 OA、审批、员工、流程场景练习，不要做电商、博客、社交 App。
代码必须上传 GitHub：这是你面试时最有力的作品展示。确保 README 写清楚项目介绍、技术栈和运行方式。
面试重点不是算法：企业更关心你能不能把系统接起来、能不能做系统集成。把 API 设计和系统集成能力练扎实。
